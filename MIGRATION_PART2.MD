## Phase 6: Create iOS MauiProgram.cs

**File**: `MobileDbBenchmark/MobileDbBenchmark.iOS/MauiProgram.cs`

Created iOS-specific MauiProgram with service registration:

```csharp
using Microsoft.Maui;
using Microsoft.Maui.Hosting;
using Microsoft.Maui.Controls.Hosting;
using MobileDbBenchamark.Common;
using MobileDbBenchmark.iOS;
using MobileDbBenchmark.UI;

namespace MobileDbBenchmark
{
    public static class MauiProgram
    {
        public static MauiApp CreateMauiApp()
        {
            var builder = MauiApp.CreateBuilder();
            builder
                .UseMauiApp<UI.App>()
                .ConfigureFonts(fonts =>
                {
                    fonts.AddFont("OpenSans-Regular.ttf", "OpenSansRegular");
                    fonts.AddFont("OpenSans-Semibold.ttf", "OpenSansSemibold");
                });

            // Register platform services
            builder.Services.AddSingleton<IStorageManager, IOSStorageManager>();
            builder.Services.AddSingleton<IMemoryService, MemoryService>();
            builder.Services.AddSingleton<IDialogService, DialogService>();

            // Configure Acr.UserDialogs
#if IOS
            Acr.UserDialogs.UserDialogs.Init(() => Microsoft.Maui.ApplicationModel.Platform.GetCurrentUIViewController());
#endif

            return builder.Build();
        }
    }
}
```

### Error 1: CS0618 - Obsolete UIApplication.Main
**Location**: `MobileDbBenchmark/MobileDbBenchmark.iOS/Main.cs:13`

## Key Technical Patterns

### iOS AppDelegate Migration Pattern
```csharp
// Before (Xamarin.Forms)
public partial class AppDelegate : global::Xamarin.Forms.Platform.iOS.FormsApplicationDelegate
{
    public override bool FinishedLaunching(UIApplication app, NSDictionary options)
    {
        global::Xamarin.Forms.Forms.Init();
        LoadApplication(new App());
        return base.FinishedLaunching(app, options);
    }
}

// After (MAUI)
public class AppDelegate : MauiUIApplicationDelegate
{
    protected override MauiApp CreateMauiApp() => MauiProgram.CreateMauiApp();
}
```

### Service Registration Pattern
```csharp
// Before (Xamarin.Forms)
[assembly: Xamarin.Forms.Dependency(typeof(IOSStorageManager))]

// After (MAUI)
// In MauiProgram.cs:
builder.Services.AddSingleton<IStorageManager, IOSStorageManager>();
```
